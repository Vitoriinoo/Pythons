# Sabor Express (Projeto de Estudos)

Fala pessoal! Esse é um dos meus primeiros projetos práticos em Python, que desenvolvi acompanhando o curso da Alura. 

A ideia aqui é simular um sistema de gerenciamento de restaurantes direto no terminal. Não tem interface gráfica ou banco de dados ainda, mas foi um exercício excelente para treinar a lógica de programação e colocar a mão na massa.

## O que dá pra fazer no sistema?
Ao rodar o código, você tem um menu simples onde pode:
- Cadastrar o nome e a categoria de um restaurante.
- Listar todos os restaurantes cadastrados (consegui deixar o texto todo alinhadinho no terminal).
- Mudar o status de um restaurante de "Ativado" para "Desativado" e vice-versa.

## O que eu aprendi com esse projeto?
Foi aqui que algumas coisas começaram a fazer sentido de verdade para mim:
- **Listas e Dicionários:** Entendi como guardar as informações dos restaurantes na memória e buscar isso depois.
- **Funções (`def`):** Vi na prática como quebrar o código em pedaços menores (uma função para cadastrar, outra para listar, etc.) deixa tudo muito mais fácil de ler e arrumar.
- **Tratamento de erros:** Usei `try/except` para evitar que o programa simplesmente feche na cara do usuário se ele digitar uma letra no lugar de um número no menu.
